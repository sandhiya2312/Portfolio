Project 2

Objective

To build a responsive and informative website for a school, where users (students, parents, or staff) can get access to all academic and administrative information easily.

Overview

Created a responsive and user-friendly school website using JSP, Java Servlet, JDBC, CSS, and MySQL. The site works well on all devices and allows users to easily access school details like Home, About, Courses, Gallery, and Contact. Displayed important school information such as academic details, faculty details, events, and image galleries. The content is well-organized, making it easy for users to explore. Added Online Admission Form for Pre-Admission and Enquiry part to mail to the offical e-mail id. Used MySQL to store and retrieve form data, helping the school manage admissions efficiently.

Project 3

Objective

To design and develop a user-friendly digital wallet application that enables users to manage their digital transactions efficiently. The application aims to provide a convenient platform for maintaining wallet balances and facilitating secure money transfers between users through a simple and intuitive interface.

Overview

Developed a Digital Wallet application using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). The application provides essential wallet management functionalities, including viewing wallet balances and sending and receiving money between users. It offers an interactive user interface and a structured backend to handle wallet-related operations efficiently. The project focuses on simplifying digital money management and providing users with a convenient digital transaction experience.

Project 4

Objective

To design and develop a dynamic and user-friendly e-commerce web application that connects Producers and Customers through a centralized online shopping platform. The application aims to simplify product management, enable customers to browse and purchase products, and provide producers with an efficient way to manage their products and customer orders.

Overview

Developed a full-stack E-Commerce website using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). The application provides separate login and registration functionalities for Producers and Customers, with dedicated profiles and role-based features. Producers can upload and manage their products through the "My Products" section and view orders received from customers. Customers can browse available products, manage their profiles, and view their order details through the "My Orders" section. The homepage dynamically displays products uploaded by Producers. The application provides an organized shopping experience while simplifying product and order management for both user roles.
